# Tasca 2: Git, viatjant pel temps

## Introducció

En aquesta activitat hem treballat amb Git i GitHub per aprendre a gestionar l'historial de versions d'un repositori. Hem practicat diferents comandes que permeten consultar canvis, recuperar versions anteriors i controlar l'evolució dels fitxers d'un projecte.

## Objectius

- Aprendre a gestionar l'historial de versions amb Git.
- Conèixer les diferents maneres de consultar els commits.
- Practicar la recuperació de versions anteriors.
- Aprendre a desfer canvis i eliminar commits.
- Millorar la documentació dels commits seguint bones pràctiques.
- Documentar els exercicis utilitzant Markdown.

## Resum de l'activitat

Durant aquesta tasca hem realitzat diferents exercicis pràctics dividits en quatre parts:

1. **Bones pràctiques en els commits:** creació del README i del fitxer de configuració de xarxa, utilitzant missatges de commit descriptius.
2. **Historial del repositori:** consulta i revisió dels commits mitjançant les comandes `git log`, `git log --oneline` i `git show HEAD`.
3. **Recuperació de versions del Working Directory:** modificació d'un fitxer i recuperació de la seva versió anterior amb `git restore`.
4. **Recuperació de commits anteriors:** pràctica de les comandes i eines `git revert` i `git reset`, exploració de commits antics i revisió de l'historial.

## Estructura del repositori

- `README.md`: descripció general de l'activitat.
- `solucions.md`: documentació dels exercicis i les solucions realitzades.
- `img/`: carpeta amb les captures de pantalla que demostren el procés i els resultats.

## Eines utilitzades

- **Git:** sistema de control de versions.
- **GitHub:** plataforma per allotjar i gestionar repositoris.
- **Visual Studio Code:** editor de codi i eina gràfica per gestionar Git.
- **Markdown:** llenguatge utilitzat per documentar l'activitat.

## Conclusió

Aquesta activitat ens ha permès entendre millor com funciona l'historial de versions de Git i com podem recuperar informació de canvis anteriors. També hem après a diferenciar entre `git restore`, `git revert` i `git reset`, tres eines útils per corregir errors i gestionar els canvis d'un projecte.
